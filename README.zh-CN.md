# Facewall

[English](README.md) | 简体中文

[![最新版本](https://img.shields.io/github/v/release/redbson/facewall-releases?label=release)](https://github.com/redbson/facewall-releases/releases/latest) [![平台](https://img.shields.io/badge/platform-macOS%2013%2B%20%C2%B7%20Apple%20silicon-555)](#要求)

Facewall 是一个本地优先、AI-native 的 **macOS 思考墙**。想法刚出现时就从任何 App 里随手丢进去；后台的 AI 把它和你过去的想法连起来，缝进持续生长的 **思考线**，发现你 **改变了主意**，让反复出现的判断浮现为 **长期模式**，并在你重新思考一个问题时 **召回过去的自己**。它用你本机已登录的 **Claude Code**、**Codex** 或 **Gemini CLI** 缝合，也可以接你配置的任何 API。没有服务器、不用注册账号：你的想法存在 Mac 上的一个数据库里，只有你选定的模型会看到它们。界面有中文和英文，默认跟随 Mac 的系统语言，可在设置里切换。

**⬇ 下载：[macOS](https://github.com/redbson/facewall-releases/releases/download/v0.3.3/Facewall-0.3.3.dmg)** · [全部版本](https://github.com/redbson/facewall-releases/releases) · [更新日志](CHANGELOG.md)

这个仓库只放安装包和更新日志；源码是私有的。

## 功能

- **随处捕捉**：全局快捷键（⌥⇧Space）在任何 App 上方弹出一个小浮窗，不抢当前 App 的焦点，回车就放到墙上。也可以从服务菜单（选中文字 → **存入 Facewall**）、菜单栏图标、Dock，以及给快捷指令、Raycast、Alfred 用的 `facewall://` URL scheme 捕捉。引擎没就绪时，捕捉会先存在本机、稍后送达——想法永远不会丢。
- **缝合**：每条线索都在后台缝合：归进一条思考线（新建或已有）、连到相关的过去线索并给出每条连接的理由、更新这条线当前的判断。Facewall 从不按规则瞎猜连接；没有 AI 时线索只是标为「待缝合」，接上模型后自动补缝。
- **观点反转**：新想法和过去的判断矛盾时，缝合会指出来，旧判断失效而不是被删掉，反转在墙上和思考线的历史里都有标记。「不是反转」可以撤销。
- **改了就算数**：把线索移到别的思考线、拆分或合并思考线、把连接标成错的、改写判断、重命名或合并概念。之后的缝合会尊重你的修改；你亲手写的判断永远不会被覆盖——AI 的新说法只作为建议出现。
- **召回**：问一个问题（⌘F），Facewall 找回你自己过去的话，带日期、逐步引用，给出此刻最站得住的判断和它的演化。它会说明自己有多大把握；过去没想过的，直接告诉你，不编造。
- **记忆与遗忘**：跨思考线反复出现的判断会成为长期模式，但要有足够证据（至少 3 条线索、跨 2 条思考线、跨 2 天）才转正——不是你的，可以否决。很久没被想起的线索会自己淡去，被打开或连接时立刻回来；也可以主动让一条线索淡去，或把它唤醒。
- **每日一针**：每天一张卡片——一条旧想法、一条思考线或一个未决问题，配一个提问。可以当场回应、从它发起召回、换一张，或今天跳过。
- **三个视图**：**思考墙**（线索按思考线分组、语义布局、标出反转）、**思考线**（每条线的判断历史和线索）、**记忆**（模式、概念、已淡去和已隐藏的线索）。
- **模型由你选**：本机的 Claude Code、Codex 或 Gemini CLI 一键启用，走你已有的订阅、不需要 API key；也支持 Anthropic、OpenAI、Azure OpenAI 和任何 OpenAI 兼容端点（DeepSeek、Kimi、GLM、Qwen、Ollama 有预设）。故障按类别区分（配额、未登录、网络、配置错误），缝合会自己恢复。
- **本地优先**：一个 SQLite 文件、每日备份、应用内恢复、完整的 JSON 导出导入，没有遥测。App 自带 Python 运行时和嵌入模型，除了调用模型，完全离线。
- **自动更新**：Facewall 会检查 GitHub Releases 上的新版本，校验后安装，见 [自动更新](#自动更新)。

## 要求

- macOS 13 或更新，Apple silicon。没有 Intel 版本。
- 一个用来缝合的模型，二选一：
  - [Claude Code](https://docs.anthropic.com/en/docs/claude-code)（`claude`）、[Codex CLI](https://github.com/openai/codex)（`codex`）或 [Gemini CLI](https://github.com/google-gemini/gemini-cli)（`gemini`，预览）已安装并登录。Facewall 用你的订阅跑它们，不需要 API key。
  - 或者 Anthropic、OpenAI、Azure OpenAI 的 API key，或任何 OpenAI 兼容端点，包括本机的 Ollama。
- 别的都不需要：Python 和嵌入模型都在 App 里。

内置嵌入模型以中文为主；英文线索的召回能用，但偏弱。

## 安装

1. 下载 [Facewall-0.3.3.dmg](https://github.com/redbson/facewall-releases/releases/download/v0.3.3/Facewall-0.3.3.dmg)（或在 [Releases](https://github.com/redbson/facewall-releases/releases) 选一个版本），打开后把 `Facewall.app` 拖进「应用程序」。
2. 首次打开：Facewall 没有经过 Apple 公证，macOS 会说无法验证开发者。打开 系统设置 → 隐私与安全性，拉到底部点 **「仍要打开」**，或者在终端执行：

   ```bash
   xattr -dr com.apple.quarantine /Applications/Facewall.app
   ```

3. 之后的版本由 Facewall 自己下载安装（见 [自动更新](#自动更新)），不会再出现这个提示。
4. 打开 Facewall，引擎大约 2 秒就绪。按 **⌘,** 连接模型：本机有 Claude Code、Codex 或 Gemini CLI 时，AI 设置顶部有一张「启用」卡片等着；否则选一个服务、填入 key。
5. 在任何 App 里按 **⌥⇧Space**，写下一个想法，回车。

要让 Facewall 开机自启，在 设置 › 外观与通用 里打开 **登录时启动**，它会常驻菜单栏，随时可以捕捉。

想先感受一下？在空墙上用 ⌘K 命令面板运行 **载入示例线索**。示例都有标记，不算你的话，一键就能清除。

## 自动更新

- Facewall 启动后不久和之后每 12 小时检查一次 GitHub 上的最新版本。不发送墙上的任何内容；检查可以关掉。
- 有新版本时，**设置 › 更新** 和侧栏底部会提示，并显示更新内容。**下载并安装** 会下载 dmg，核对它的 SHA-256 校验和、包标识、版本号和代码签名，全部一致才暂存新版；**重启并更新** 把它换进去并重新打开 Facewall。下载好但没重启的，下次退出时安装。
- **自动下载更新** 会在后台完成下载和校验，退出时安装。
- 如果 Facewall 是从安装盘、macOS 的隔离位置或一个你没有写入权限的文件夹里运行的，它无法替换自己，会指引你去发布页。
- 从 0.3.2 及更早版本升级，需要手动装一次 0.3.3；之后的版本都在应用内升级。

## 使用

### 放下线索

- **墙上**：⌘N 或底部的输入框；⌘↩ 放到墙上。一条线索一个想法，没想完也没关系。最多 20,000 字。
- **快速捕捉浮窗**：在任何 App 里按 ⌥⇧Space（可在 设置 › 快捷键 改）：↩ 放下并关闭；⌥↩ 放下并继续写下一条；⌘↩ 放下并打开 Facewall；⇧↩ 换行；⇥ 切到召回；Esc 关闭。用拼音或注音输入法时，回车只选字，不会误提交。
- **从别处**：在任何 App 里选中文字 → 右键 → 服务 → **存入 Facewall**（可在 系统设置 › 键盘 › 键盘快捷键 › 服务 里绑定快捷键）；菜单栏图标和 Dock 图标的菜单；`facewall://capture?text=…` 静默放下一条线索，`facewall://quick` 打开浮窗，`facewall://recall?q=…` 召回。
- 窗口外捕捉的线索缝合完成后会有系统通知；默认不带原文。

### 读懂一次缝合

选中一条线索，右栏的 **缝合** 页依次显示：归进了哪条思考线、发现的反转（如果有）、连到的过去线索和每条连接的理由、这条线索之后思考线的判断、模型标记的新模式（如果有）、AI 的完整推理，以及一个 **下一针** 提问——可以当场回应，也可以从它发起召回。右上角的状态显示 AI 在做什么（就绪、缝合中、未配置、暂停及原因）；⇧⌘S 缝合全部待缝合线索。

### AI 缝错了怎么办

| | |
|---|---|
| **这条连接不对** | 降权并停用这条连接；它从墙上和召回里消失。 |
| **不是反转** | AI 让它失效的旧判断恢复。 |
| **移到…** | 把线索放到正确的思考线或新建一条；之后的缝合不会再移回去。**拆分到新思考线** 把混进来的另一件事拆出去；合并会先确认，10 分钟内可撤销。 |
| **编辑**（思考线） | 改写标题或判断。你的判断会被标出来、永远不会被改写；AI 的新说法以建议出现，采用或忽略由你定。 |
| **这不是我的模式**（记忆） | 否决一个长期模式；以后可以恢复。 |
| **重命名概念**（记忆） | 改成已有的名字就会合并。 |

每一次修正都是信号：AI 推断什么都可以，最终解释权在你。

### 召回

按 ⌘F（不在输入时按 `/` 也行），写下你想继续思考的事，回车。像问一个了解你的人那样问：*关于要不要搬去另一个城市，我反复纠结过什么？* 结果先说有多大把握，然后是此刻最稳的判断、观点随时间的演化（每一步都能跳到对应线索）、未决的问题、相关思考线、召回的原话——带日期，全是你自己的话——以及折叠起来的「最接近但不确定」和「已淡去」两组。**从这里继续想** 把你的回应变成一条新线索。

### 每日一针

缝合页空闲时会出现一张卡片：一条旧想法、一条思考线或一个未决问题，配一个提问。**写下回应**、**召回过去的我**、**换一张**，或 **今天不看**。示例和已淡去的线索不会出现在里面。

### 思考线与记忆

- **思考线**（⌘2）：每条线的线索、当前判断和它的演化，标出反转和「改变过主意」；可以编辑、拆分、合并，或导出为 Markdown（⌘E）。
- **记忆**（⌘3）：长期模式及其证据（转正前为「待观察」）、按成熟度排列的概念，以及已淡去、已隐藏的线索，可 **唤醒**、**恢复**。
- 墙上：⌘⌫ 删除选中的线索，也可以隐藏它，或让它淡去。删除或隐藏的线索不会再出现在任何地方——包括由它派生的判断、概念和模式——也不再发给模型。

### 设置（⌘,）

- **AI 模型**：服务商、模型、连接测试，以及本机 CLI 的一键启用卡片。缝合可以用比召回更便宜的模型。
- **外观与通用**：浅色 / 深色 / 跟随系统，四种深色风格；语言（简体中文、English、跟随系统）；登录时启动；菜单栏和 Dock 图标；通知以及通知是否带原文。
- **快捷键**：两个全局快捷键（快速捕捉、显示 / 隐藏 Facewall）和其他快捷键一览。
- **数据与引擎**：数据目录（显示、更换）、导出导入、备份与应用内恢复、使用统计、认知内核、日志、重启引擎。
- **更新**：当前版本，检查 / 下载 / 安装，两个自动开关，版本日志。

## 数据与隐私

| 什么 | 在哪 |
|---|---|
| 你的墙 | `~/Library/Application Support/Facewall/Data/facewall.db`——所有线索、连接、判断、模式和向量都在这一个 SQLite 文件里。目录可在 设置 › 数据与引擎 里更换。 |
| 备份 | `…/Data/backups/`——最近 7 天每天一份，最近 5 份手动备份，以及每次升级、导入、恢复前各一份。在设置里可以恢复到任意一份。 |
| 模型配置 | `…/Data/llm_config.json`，仅本人可读。key 永远不会回传到界面。 |
| 等待引擎的捕捉 | `~/Library/Application Support/Facewall/outbox.jsonl` |
| 日志 | `~/Library/Logs/Facewall/app.log` 和 `engine.log`（帮助 › 打开日志） |

- 只有这些会发给你配置的模型：正在缝合的线索、与它最相关的几条过去线索、涉及的思考线判断；召回时是你的问题和召回到的线索。OpenAI 和 Azure 的请求会要求服务端不保存。
- 其余全在本地：命令面板的搜索、嵌入模型、布局、使用统计、更新检查（只向 GitHub 问最新版本号）。
- ⇧⌘E 把全部数据导出为 JSON，原文逐字保留；⌘O 导入。Facewall 写的文件都只有你能读。
- 快速捕捉浮窗、服务菜单和系统通知默认不显示原文；线索删除后，它的通知会被撤回。

## 排查问题

- **macOS 不让打开**：见 [安装](#安装) 第 2 步。只有手动安装的副本会遇到这个提示，应用内更新不会。
- **右上角显示「未配置 AI」**：点它。本机有 `claude`、`codex` 或 `gemini` 却找不到时，在终端里运行一次并登录，或在 设置 › AI 模型 里填入命令路径。
- **「缝合已暂停」**：状态会说明原因——配额用完、未登录、断网或模型配置错误——以及何时重试。⇧⌘S 立刻重试；配置错误会带你去设置。
- **一条捕捉被拒绝**：浮窗（或通知）会说明原因，通常是超过 20,000 字，并让你把原文复制回去。
- **引擎起不来或没有响应**：帮助 › **重启引擎**，再用 帮助 › **打开日志** 看 `engine.log`。引擎卡死会自动重启；两份 Facewall 不会同时打开同一个数据目录。
- **更新失败**：设置 › 更新 会显示原因。你随时可以从 [Releases](https://github.com/redbson/facewall-releases/releases/latest) 下载最新 dmg 覆盖安装；数据、设置和备份都保留。
- **升级后不对劲**：设置 › 数据与引擎 › 备份 里有升级前那一份；恢复前会再备份一次。
