# 当前状态（2026-10-14，0.3.1）

## 一句话

引擎和捕捉底座扎实，这两天把"写在界面上的承诺"一条条兑现了（判断不被覆盖、删除即消失、捕捉不丢、备份能恢复、退出干净），
并把每次缝合算出来的东西真正送到眼前。接下来最缺的不是功能，而是 **真实使用数据**：作者本人的日常使用刚开始，
AI 质量相关的决定（相关度阈值、嵌入模型、提示词）都要等真实线索的评测集。

## 核心循环逐环

| 环节 | 状态 | 说明 |
|---|---|---|
| 捕捉 | ✅ 稳 | 浮窗 / 服务菜单 / URL / 终端；暂存队列不卡死、不丢、不重复；引擎卡住时 8 秒内转暂存 |
| 缝合 | ✅ 可靠 | 真实模型实测：Claude Code · sonnet 约 15 秒/条，Codex · gpt-6-sol 约 43 秒/条，0 失败；故障分类与自动恢复 |
| 思考线 | ✅ | 用户判断优先、判断历史、反转可见、可移动 / 拆分 / 合并撤销 |
| 模式 | ⚠️ | 门槛严格（第一周多为空）；陈述仍是模板句 |
| 召回 | ✅ 新 | 分把握三档，无关时放弃；每步引用原话；遗忘与唤醒 |
| 每日一针 | ✅ | 常驻可见；排除示例与已淡去的线索 |
| 数据与隐私 | ✅ | 应用内恢复备份、备份分桶、迁移原子、文件 0600、通知不带原文 |
| 分发 | ⚠️ | ad-hoc 签名未公证、仅 Apple Silicon、仅中文；无自动更新 |

## 已知限制

- 召回相关度的阈值尚未用真实数据校准：短而泛的问题可能把只共享常见字的线索也算成相关。
- 隐性的观点反转（没明说"改变主意"）识别不稳定，取决于模型；Codex 比 Claude Code 慢约 3 倍。
- 模式层第一周基本空白，浮现时的陈述是模板句。
- 恢复旧备份或导入旧导出，会让之后删除的线索重新出现（恢复前有提示）。
- 未签名公证：首次打开需手动去掉隔离标记；没有 Sparkle 式自动更新，需要手动下载新版。
- 只支持中文界面与中文模型输出；嵌入模型为中文模型（bge-small-zh）。
- 数据目录放在 iCloud / 网盘会收到警告但不阻止——不建议这样做。
